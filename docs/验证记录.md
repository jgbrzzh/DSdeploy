## 测试中发现并修复的问题

1. Docker Hub 连接出现 EOF，增加有限次数下载重试与本地导入，默认改用 DaoCloud，保留毫秒镜像和原站选项。
2. 多个 RepoDigests 在 Windows PowerShell 5.1 中可能被错误序列化为对象；现在显式展开为字符串并优先保留当前镜像源。
3. 普通 CLI stderr 进度可能被当成终止错误；现在依据进程退出码判断，缺失模型作为可恢复分支处理。
4. 业务备份可能误收运行中的虚拟磁盘；现在只归档业务目录、保留原相对路径，失败产物标记为 .partial。
5. Fake-IP DNS 导致 Ollama 拒绝模型 CDN 地址。现仅针对官方仓库及其返回的受限 CDN 域名查询真实公网地址，并应用到本包 Ollama 容器；不修改系统 DNS，不关闭地址检查。随后模型下载与摘要校验成功。
