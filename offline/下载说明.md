# 在网络畅通的电脑下载，再带到目标电脑

官方页面：

- AstrBot 镜像：https://hub.docker.com/r/soulter/astrbot
- NapCat 镜像：https://hub.docker.com/r/mlikiowa/napcat-docker
- Ollama 镜像：https://hub.docker.com/r/ollama/ollama
- Docker Desktop Windows x64 安装器：https://desktop.docker.com/win/main/amd64/Docker%20Desktop%20Installer.exe
- bge-m3 模型说明：https://ollama.com/library/bge-m3

Docker Hub 页面不是可以直接下载的镜像 ZIP。需要在已运行 Docker 的联网电脑上，解压部署包后双击「下载镜像包.cmd」。它会下载三个镜像并导出为本目录的 images.tar，另有 SHA-256 校验文件。
下载器默认走 DaoCloud 国内镜像入口，然后打回标准镜像标签再导出；可用 `powershell -File .\Deploy.ps1 -Action ExportImages -ImageSource 1ms` 切换到毫秒镜像，或 `-ImageSource Official` 使用原站。
把整个 offline 文件夹复制到目标部署包根目录；启动器会先校验并导入镜像，对已导入的镜像跳过在线拉取。

也可以自己执行：

```powershell
docker pull soulter/astrbot:latest
docker pull mlikiowa/napcat-docker:latest
docker pull ollama/ollama:latest
docker save -o images.tar soulter/astrbot:latest mlikiowa/napcat-docker:latest ollama/ollama:latest
```

如果只下载 Docker 安装器，请命名为 DockerDesktopInstaller.exe，放入部署包的 runtime/downloads，再双击「安装Docker.cmd」。

当前导出的是三个基础镜像，插件依赖构建和 bge-m3 模型首次下载仍需网络，DeepSeek 聊天也需联网调用 API；这不等于完全离线部署。
不要把真实 API Key、QQ 登录目录或运行数据分享进公开部署包。分发较大的镜像档案前请保留对应上游许可与来源。
